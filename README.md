# LeetCode Solutions

A growing collection of my LeetCode solutions, automatically synchronized from LeetCode to GitHub using a custom browser extension, with AI-generated explanations powered by Google Gemini.

This repository serves as a record of my Data Structures and Algorithms (DSA) practice, helping me understand problem-solving techniques, analyze algorithm efficiency, and revisit concepts as I continue learning.

## What You'll Find Here

- **LeetCode Solutions:** My submitted solutions, primarily written in C++, with implementations in other languages when applicable.
- **AI-Generated Explanations:** Detailed explanations of the approach and algorithm used to solve a problem.
- **Step-by-Step Reasoning:** Readable walkthroughs that explain how the solution works.
- **Complexity Analysis:** Time and space complexity analysis to understand algorithm efficiency.
- **Organized Solutions:** Problems grouped by difficulty, topic, and problem name.

## Automated Workflow

I use my custom [LeetCode → GitHub Sync](https://github.com/thrishi1011/leetcode-github) browser extension to maintain this repository.

1. Solve a problem on LeetCode and get an accepted submission.
2. Click the **Push** button on the problem page.
3. The extension pushes the solution code to this repository.
4. When Gemini is configured and explanation generation succeeds, an `explanation.md` file is added alongside the solution.

This workflow reduces manual copying and documentation work, allowing me to focus more on solving problems and understanding the underlying algorithms.

## Problem Organization

Solutions are organized by difficulty and topic, with a separate directory for each problem. Depending on the problem and available files, a directory may contain the solution code and its corresponding explanation.

## My Approach to DSA

I aim to understand not only how a solution works, but also why a particular approach is suitable for a problem. I use these solutions and explanations to strengthen my understanding of algorithms, improve problem-solving efficiency, and prepare for technical interviews.

AI-generated explanations are useful learning aids, and I review them when needed to verify their correctness.

This repository evolves continuously as I solve new problems, explore different approaches, and improve my understanding of Data Structures and Algorithms.
